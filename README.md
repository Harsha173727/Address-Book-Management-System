📖 Address Book Management System

A console-based Address Book Management System developed in C programming. This application helps users efficiently manage contact information by providing features such as adding, searching, editing, deleting, and listing contacts. Data is stored permanently using file handling techniques.

🚀 Features
✅ Add New Contact

✅ Search Existing Contact

✅ Edit Contact Details

✅ Delete Contact

✅ Display All Contacts

✅ Contact Validation

✅ CSV File Storage

✅ Modular Programming Approach

✅ Menu Driven Interface

📋 Functionalities
➕ Create Contact
Add a new contact to the address book.
Store Name, Mobile Number and Email Address.
Validate user inputs before saving.
🔍 Search Contact
Search contacts using:
Name
Mobile Number
Email Address
✏️ Edit Contact
Update contact information.
Modify existing contact fields.
❌ Delete Contact
Remove unwanted contacts permanently.
📃 List Contacts
Display all available contacts.
View complete address book information.
✔️ Validation
Mobile number validation.
Email validation.
Duplicate entry checking.
💾 Data Storage
All contacts are stored in:

contact.csv
This ensures that data remains available even after the application is closed.
